🚀 QUICK START GUIDE
═════════════════════════════════════════════════════════════════════════════

⏱️ 5 MINUTES - Development Setup:

   $ set ASPNETCORE_ENVIRONMENT=Development
   $ dotnet restore
   $ dotnet run
   
   ✅ Application available at https://localhost:5001

⏱️ 15 MINUTES - Staging Setup:

   1. Edit appsettings.Staging.json
   2. Update ConnectionStrings with staging database
   3. $ set ASPNETCORE_ENVIRONMENT=Staging
   4. $ dotnet run
   
   ✅ Application configured for staging

⏱️ 30 MINUTES - Production Setup:

   1. Set ASPNETCORE_ENVIRONMENT=Production (permanently)
   2. Configure secrets:
      $ dotnet user-secrets set "JWTSettings:Key" "..."
      $ dotnet user-secrets set "ConnectionStrings:Postgres" "..."
   3. $ mkdir -p /var/log/courtapp
   4. $ dotnet run --configuration Release
   
   ✅ Application ready for production
