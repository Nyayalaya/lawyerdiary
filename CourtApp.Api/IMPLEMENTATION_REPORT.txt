LOGIN ENDPOINT SPECIFICATION
────────────────────────────────────────────────────────────────────────────

Route: POST /api/auth/login
Authentication: AllowAnonymous
Content-Type: application/json

Request Body:
{
  "emailOrUsername": "string (required)",
  "password": "string (required)",
  "rememberMe": "boolean (optional)"
}

Success Response (HTTP 200):
{
  "status": true,
  "message": "Login successful",
  "data": {
    "userId": "string (GUID)",
    "username": "string",
    "email": "string",
    "firstName": "string",
    "lastName": "string",
    "token": "string (JWT token)",
    "refreshToken": "string",
    "tokenExpiration": "datetime",
    "roles": ["string"]
  },
  "statusCode": 200,
  "timestamp": "datetime",
  "traceId": "string"
}

Error Response (HTTP 401):
{
  "status": false,
  "message": "Invalid login attempt",
  "errors": [],
  "statusCode": 401,
  "timestamp": "datetime",
  "traceId": "string"
}

Validation:
  ✓ ModelState must be valid
  ✓ EmailOrUsername is required
  ✓ Password is required
  ✓ User must exist in database (TODO: integrate UserManager)
  ✓ User password must be correct (TODO: integrate UserManager)
  ✓ User must be active (TODO: integrate)
  ✓ User email must be confirmed (TODO: integrate)

────────────────────────────────────────────────────────────────────────────

REGISTER ENDPOINT SPECIFICATION
────────────────────────────────────────────────────────────────────────────

Route: POST /api/auth/register
Authentication: AllowAnonymous
Content-Type: application/json

Request Body:
{
  "email": "string (required, valid email)",
  "username": "string (required, 3-100 chars)",
  "firstName": "string (required)",
  "lastName": "string (required)",
  "password": "string (required, 8+ chars, upper, lower, digit)",
  "confirmPassword": "string (required, must match password)",
  "phoneNumber": "string (optional, valid phone format)"
}

Success Response (HTTP 201):
{
  "status": true,
  "message": "User registered successfully. Check your email for confirmation link.",
  "data": {
    "success": true,
    "userId": "string (GUID)",
    "message": "Registration successful. Please confirm your email address.",
    "errors": []
  },
  "statusCode": 201,
  "timestamp": "datetime",
  "traceId": "string"
}

Error Response (HTTP 400):
{
  "status": false,
  "message": "Invalid registration request",
  "errors": [
    "Email is required",
    "Username must be between 3 and 100 characters",
    "Password must be at least 8 characters and contain uppercase, lowercase, and numbers"
  ],
  "statusCode": 400,
  "timestamp": "datetime",
  "traceId": "string"
}

Validation:
  ✓ ModelState must be valid
  ✓ Email is required and valid format
  ✓ Username is required and 3-100 characters
  ✓ FirstName is required
  ✓ LastName is required
  ✓ Password is required and meets strength requirements
  ✓ ConfirmPassword is required and matches Password
  ✓ PhoneNumber (if provided) must be valid format
  ✓ Email must not already be registered (TODO: integrate UserManager)
  ✓ Username must not already be taken (TODO: integrate UserManager)
