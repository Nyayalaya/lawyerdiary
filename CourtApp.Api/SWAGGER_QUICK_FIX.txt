## 🔐 JWT Authorization in Swagger

### Step 1: Get Token
1. POST to `/api/auth/login`
2. Use valid credentials
3. Copy token from response

### Step 2: Authorize
1. Click "Authorize" button
2. Paste: `Bearer eyJhbGciOi...`
3. Click "Authorize"

### Step 3: Test Protected Endpoints
- Now you can test endpoints with `[Authorize]`
- Token automatically included
- See authenticated responses

```csharp

{
    app.UseSwagger();
    app.UseSwaggerUI(c =>

        c.RoutePrefix = ""; // Root path
```

## 🆘 Troubleshooting

### Problem: Still getting 404
**Solution:**
- Verify environment: Development
- Check port: 5001 (not 7246)
- Restart application
- Clear browser cache

### Problem: Swagger UI blank
**Solution:**
- Verify controllers exist
- Check `[ApiController]` attribute
- Verify `[HttpGet]`, `[HttpPost]` attributes
- Rebuild solution

### Problem: Can't authorize
**Solution:**
- Verify token format: `Bearer {token}`
- Check token is valid
- Verify `[Authorize]` on endpoint
