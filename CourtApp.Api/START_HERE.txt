💡 KEY CONCEPTS
═════════════════════════════════════════════════════════════════════════════

BaseController:
   - Abstract controller inherited by all API controllers
   - Extracts user from JWT claims
   - Provides role checking methods
   - Provides response helper methods

UserContextInfo:
   - Contains all user information
   - Extracted from JWT claims
   - Helper methods for role checking
   - Available in all controller actions

ApiResponse:
   - Standardized response wrapper
   - Generic version: ApiResponse<T>
   - Non-generic version: ApiResponse
   - Consistent JSON format
